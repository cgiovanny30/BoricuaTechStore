BORICUA TECH STORE
Proyecto Final de Desarrollo Web

Descripción:
Boricua Tech Store es una tienda en línea de productos tecnológicos. El sitio web fue desarrollado utilizando HTML5, CSS3, Bootstrap y JavaScript.

El proyecto contiene una página principal y diez páginas subordinadas. El sitio permite navegar por diferentes categorías de productos, consultar ofertas, conocer información sobre la tienda, revisar preguntas frecuentes, consultar políticas y utilizar un formulario de contacto.

Tecnologías utilizadas:
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Visual Studio Code
- GitHub

Funciones principales:
- Diseño responsivo para computadoras, tabletas y dispositivos móviles.
- Barra de navegación entre las diferentes páginas.
- Carrusel de imágenes en la página principal.
- Efectos visuales al pasar el mouse sobre los productos.
- Botones interactivos para mostrar detalles de los productos.
- Validación en tiempo real del formulario de contacto.
- Uso de elementos semánticos de HTML5.
- Estilos personalizados mediante CSS.
- Componentes responsivos de Bootstrap.
